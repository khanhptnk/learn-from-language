PER PROPOSAL

1. R-GFT (feedback-model-inversion). Operator (self-normalized reweighting of own samples, weighted BC, replay) is the one piece every lens passed; it is Lemma 4.1 in sample form and never reads a word. Recipe parts: CONTENT_WORDS slot grammar, skel(f) from the crafted template, 16-step window max, zero-variance column zeroing, OOV rule that happens to match the split, infer_ideal as G*. Coverage fails: output factorization leaves the input joint intact, "rope" never precedes "and", the station is a function of the inputs in every seen craft, and (site, rope+brick, CRAFT) is censored (0 of 74 steps).

2. SN-GFT (language-value). Fixed product/argmax operator. Recipe parts: chain-rule slots are the template's fixed frame, claim_steps event times, the inventory vector for input factors, infer_ideal.ideal with a transitive-closure subgoal sentence, proposed teacher wording edits. Coverage: hindsight density (1.34 positives/step) is real and transplants; chain-rule composition does not (P(rope | "at a site from") has zero support; F has its own survivor bias at the fence state, 0 of 39 labels mention the site). The per-word reachability twin B is the only transplantable scorer.

3. RD (learned-operator). Recipe parts: inventory-change keyframe detector, praise parse, same-world resets, [DROP] semantics, sessions whose next attempts are 50% expert solves. Coverage fails at the last edit: the input set determines the station in all 8 seen recipes, so MLE has no pressure to read "at a <station>"; elimination is a holding-to-station lookup; the desired slot carries the narrated answer in training and is empty at test. The fence proxy cannot falsify it (stone implies site everywhere).

4. HSQ (hindsight-relabeling). Relabel plus Bellman max is fixed. Recipe parts: exhaustive attempt narration (4.8 sentences per message, 91% re-narrating successes), subset relabeling, a frame classifier for negatives, hint-to-attempt compiler, event-log timestamps, a 7-action max. Coverage: counts reproduce but are marginal; the well row has zero exact entries; the priority rule makes fence (28 presses) and sling (100) seen under supersets, so only the well is zero-shot; the relabel is a function of the agent's own state, so the words add nothing.

5. HNH (skills-from-language). The most generally stated loop (HER x HAL under Stage I/II). Recipe parts: RELABEL reads claim tuples and claim_steps (an event-log stage detector), the complete-narration profile, the V* template, CONTENT_WORDS/GOALS dropout, cross-attempt windows (constructed pairs). Coverage fails at pi_hi's station slot: item to station is deterministic in every training sentence, so copy-from-hint is unidentifiable from lookup; the executor's 43-47% is the control rate (seen wall 49%).

6. Checklist (existing-paradigms). Honest paradigm map, GFT operator untouched. Recipe parts: the scheduler is the recipe schema ("hold inputs, stand at station, press one action"), claim_steps spans, a template rule naming the station in every craft, inventory dropout from world knowledge, infer_ideal G*, the 0.95 cosine covered check; the 10.2% came from an inventory-switched harness. Per-word reachability is dense, but role noise (29-63% consumed at span end) and the latch rules do the composition.

7. MB-GFT (model-based). Fixed operator. Recipe parts: a content/skeleton partition not recoverable by frequency (planks 584 outrank made 397), simulator spans with no span source for imagined candidates, infer_ideal G*, tile world model, HUD. The world model is dispensable by its own admission. Coverage fails as R-GFT's: 7-8 consumption patterns; the stone-site shortcut agrees with the tile on the fence and disagrees on well and sling.

WHAT IS MISSING

A. Identifiability was never computed before anyone designed. From core.RECIPES, in all 8 seen recipes the input set determines the station and the item determines both; the conditional information between the station word and the station given the held inputs is zero on the training distribution, and rope never occupies the first input slot. No general objective can learn to read a slot that is redundant in every instance. This is a property of the instance, not of any paradigm: MiniCraft as configured cannot falsify a paradigm on this axis, it can only return nulls, which is what every generalization verifier predicted for all seven. The brief's option 1 is therefore misdescribed as "changing the game": a minimal version (one pair of seen recipes sharing an input set at two stations, drop filter and wording unchanged) is the coverage condition the instance must meet, exactly as HER needs an achievement test. Hidden shared assumption: that eight recipes could suffice for any design.

B. Censoring. The drop filter deletes every (site, rope+brick, CRAFT) transition and leaves 74 steps at that state with zero crafts, so every imitation-trained component is trained against the needed action. All seven inherit this; no fixed operator removes it; it should be a standing caveat of this realism rule.

C. Full observability. verify.py reconstructs all 77,600 sentences from the trajectory, so descriptive feedback carries nothing the agent cannot compute; only prescriptive content (hints, needed) is informative, and the brief's rule reads prescriptive content as a shaping spec in words. The constraints plus full observability may be jointly unsatisfiable. The angle nobody took: hidden state the teacher can name, where hindsight language is informative and no shaping function can be written without reading it.

D. G*. All seven route the only new information through infer_ideal's regex over hint_recipe. Nobody asked the teacher for the success narration (the plan_facts route exists) or costed that access per the paper's item 7.

E. Recognition easier than generation: assumed by four proposals, shown unproven by three verifiers (output factorization keeps the input joint; the HUD gives a perfect station shortcut; the fence proxy cannot test it).

F. No proposal included PPO or RWR on r = log F_theta(f*|x) with the same G*, the only comparator that separates the operator from the critic.

Verdicts I think are wrong. (1) The realism verdicts that fail R-GFT and Checklist because PPO with oracle shaping on {rope, brick, site} would tie: the brief says a reward-shaping story must explain the win equally well; a shaping function written by someone who read the recipe is not available without the words. The information-matched comparator is a reward learner fed the same message (PPO reward=parse, FeedbackRL), the regime of the brief's own L1 finding. Read literally, that comparator makes every language win impossible in a fully observed world; weak, not fail, and the user should rule. (2) Verdicts faulting the inventory vector apply a stricter rule than the established base the brief lists as given; flag, do not fail. (3) HSQ's generalization verdict is too generous at "weak": its own finding that fence and sling are seen under supersets voids the gate design.

COMBINED PARADIGM: explicit-EM GFT with a verifier teacher

Loop (any environment). (1) Sample N trajectories per request from pi_t, per-step mixed with the frozen text-free base. (2) The teacher narrates each in hindsight and, on request, states what a success would be described as (G*, a declared and costed resource) and answers true/false/unknown for any (episode, sentence) pair. (3) Fixed operator: w_n proportional to F_theta(f*|x_n), self-normalized within the request (top-k is best-of-N); weighted BC of pi under the request alone, with replay. (4) Refit F_theta by MLE on the round's (x, f) pairs and on verifier-labelled cross pairs. (5) Optional word-level HER explorer (twin B), declared as exploration, never as improvement.

Learned. pi as now. F_theta(f|x): a conditional language model of the whole feedback given frames and actions; every word scored, no content list, no window machinery, request dropped, inventory channels with zero training variance dropped. V(s|w) from span ends, for exploration only.

Fixed. The reweight-and-imitate step, which sorts and averages numbers and therefore never generalizes; the verifier relabel (true of x is a positive, false is a negative), which gives HER's transition-by-goal product without a designer-chosen frame.

Coverage. Hindsight density plus the verifier cross product, under a pre-registered condition: F_theta can score a never-seen f* only if each content word of f* carries positive conditional information given the others in the training distribution. MiniCraft fails it today; the paradigm predicts its own null and says so.

Instance and test. CPU first: compute the condition from RECIPES and the corpus (expected zero), then the splice test (the 74 replay steps plus CRAFT, scored by an inventory-blind F_theta against wall and near-miss windows; falsifier AUC below 0.6). If the user adopts the minimal identifiability change, retrain 31 minutes and rerun. Comparators: PPO success, PPO reward=parse, PPO/RWR on log F_theta(f*|x) with the same G*, permuted-f* and other-composite ablations; words count only if full beats both reward arms at equal teacher calls and the permuted and other-composite arms collapse.

Combining beats any single proposal: it keeps the one operator all lenses passed, removes every named environment part except a declared G*, and adds the two things nobody had, a verifier interface for negatives and an identifiability condition that turns the expected null into a measured one.
